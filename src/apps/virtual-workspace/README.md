# Virtual Workspace App

This demo app validates the toolkit in an open-ended object manipulation scenario.

The app consumes canonical actions from the collaboration core and renders a
free-form 3D workspace instead of the shape puzzle's task-specific targets and
scoring.

## Launch

From the repository root:

```bash
cd src
python3 apps/virtual-workspace/app.py
```
